# Chase

A Vector-style parkour chase game. Reach the flag before the hunter catches you.

- Swipe up to jump, swipe down to slide (tap also jumps)
- Keyboard: Space / Up to jump, Down / S to slide
- Works offline as an installable PWA

## Play on GitHub Pages
Repo Settings > Pages > Deploy from branch > `main` / root. Open the URL it gives you.
